このサイトについて

ブラウザだけで遊べる 3D 将棋です。インストール不要で、CPU 対局・同じ端末での対人戦・オンライン対戦（P2P）ができます。

ルール

  • 二歩・打ち歩詰め・行き所のない駒・王手放置は指せません。
  • 同一局面が4回現れると千日手（引き分け）。一方が王手をかけ続けていた場合はその側の反則負けです。
  • 入玉宣言は 24点法：玉が敵陣にいて王手されておらず、敵陣の自駒が10枚以上のとき宣言できます。大駒5点・小駒1点で31点以上なら勝ち、24〜30点なら持将棋（引き分け）。駒落ちでは上手の落とした駒を上手の点に加えます。
  • 「待った」は CPU 戦と対人（ローカル）戦で使えます。オンライン対戦では使えません。

CPU エンジン

CPU には将棋ソフト「やねうら王」の WebAssembly 版（YaneuraOu.wasm、 @mizarjp/yaneuraou.k-p 7.6.3）を使い、 評価関数は内蔵の「水匠Petite」（たややん氏）です。お使いのブラウザ内で動作し、局面がサーバーに送られることはありません。 エンジンは GNU GPL v3 で配布されており、ライセンス全文は こちら、 ソースコードは上記リンク先で入手できます。

エンジンを動かすには WebAssembly のスレッドと SIMD が必要です（最新の Chrome / Edge / Firefox / Safari 16.4 以降）。 非対応の環境では、内蔵の簡易 AI が代わりに指します。
